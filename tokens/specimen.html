Fundo design tokens

Built from the fundo.com brand: Outfit for headings, Roboto for text, primary #0E90E4. Every scale moves lightness ±10 per step from its 500; neutrals take the primary’s hue. Semantic tokens map each role to a step for light and dark mode, and every text/background pair is checked against WCAG AA by the build script.

Primitive palette

W = contrast against white, D = against neutral‑900. #0E90E4 reaches only 3.4:1 on white, so it is the brand colour (logo, large headings, icons, focus); actions and links use primary‑600 (5.2:1).
